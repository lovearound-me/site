WebSocket

The event stream: a device keeps the connection open, and the server pushes signals into it the moment they’re sent.

Overview REST API WebSocket ESP32 toy

Connecting

WS/v1/streamdevice, receive permission
wss://api.lovearound.me/v1/stream
Authorization: Bearer dev_…

The token goes in a header, as with REST. The browser’s built-in WebSocket can’t set headers, so connect from your own program: on a board, in Node, Python, on a phone.

Parameter
anyone=trueReceive “someone out there” signals from strangers. Off by default for devices, on for the apps. Nothing is stored: each connection decides for itself
anyone=falseDon’t receive them

Responses to connecting:

CodeWhat to do
101The connection is open; ready comes next
401The token is wrong, or the device was disconnected. Reconnecting won’t help
403The device doesn’t have the receive permission
503The server is updating. Connect again in a couple of seconds

Messages from the server

Each message is a text frame with one JSON object. The type field says what kind of message it is.

ready

{ "type": "ready" }

The first message after connecting: from now on, signals are delivered. Things may have changed while you were disconnected, so on every ready reload whatever you keep locally, such as the contact list.

event

{
  "type": "event",
  "event": {
    "id": "ev_q8ZkT1mW4aLp0sXv7cRb",
    "type": "signal",
    "v": 1,
    "at": "2026-10-10T14:00:00.000Z"
  }
}
Field
event.idThe event’s identifier. One event reaches all of the recipient’s devices with the same id
event.typeOnly signal for now
event.vThe format version of this type. For signal it’s 1
event.atWhen the server accepted the event

Someone sent you a heart — time to glow. The event has no sender. A signal from a close one and a signal to “anyone” look exactly the same.

sync

{ "type": "sync", "what": "contacts" }

The contact list changed: someone was added, renamed, moved or removed. If your device shows the list, reload it with GET /v1/contacts. If it doesn’t, you can skip this message.

Skip what you don’t know. If you don’t recognise the type, event.type, event.v or what, do nothing. The server will add new messages, and older devices should quietly ignore them.

From client to server

Nothing. The stream is one-way; the server ignores anything you write to it. Send signals with POST /v1/events: sending has one path, and every check and limit lives in one place.

Keeping the connection alive

  • Ping. The server pings every 25 seconds; well-behaved clients answer with pong on their own. Send your own ping too, every 30 seconds: if no pong comes back within a few seconds, the connection is dead, even if the socket doesn’t know it yet.
  • Reconnecting. Connections drop: Wi‑Fi goes away, the server updates. On an update the server closes old connections itself so everyone moves to the new version. Reconnect with a pause: start at one second and double it up to a minute; after ready, reset it to one second.
  • When not to reconnect. If connecting returns 401, the device was disconnected or the token is wrong. Tell the owner instead of hammering the server.
  • The server closes the stream itself when the device is disconnected in the app or the account is deleted.

Several connections

One account can have any number of open streams: Mac, Windows, a toy, a lamp. Every event reaches each of them. One device can also hold several connections, but one is usually enough.

Only streams with anyone=true get “anyone” signals. One person gets such a signal at most once an hour.

Examples

From a terminal

With websocat:

websocat -H "Authorization: Bearer dev_…" \
  wss://api.lovearound.me/v1/stream

Node.js

With the ws package (npm i ws):

import WebSocket from "ws";

const URL = "wss://api.lovearound.me/v1/stream";
const TOKEN = process.env.LOVEAROUND_TOKEN; // dev_…
let delay = 1000;

function connect() {
  const ws = new WebSocket(URL, { headers: { Authorization: `Bearer ${TOKEN}` } });

  ws.on("message", (data) => {
    let msg;
    try { msg = JSON.parse(data); } catch { return; }
    if (msg.type === "ready") { delay = 1000; console.log("online"); }
    if (msg.type === "event" && msg.event?.type === "signal" && msg.event?.v === 1) {
      console.log("💗 someone thought of you");
    }
    // skip everything else
  });

  // ping every 30 s; no pong by the next one means the connection is dead
  let alive = true;
  ws.on("pong", () => { alive = true; });
  const ping = setInterval(() => {
    if (!alive) return ws.terminate();
    alive = false;
    ws.ping();
  }, 30_000);

  ws.on("error", (err) => {
    if (err.message.includes("Unexpected server response: 401")) {
      console.error("the token doesn't work");
      process.exit(1);
    }
    // an error is always followed by close
  });

  ws.on("close", () => {
    clearInterval(ping);
    setTimeout(connect, delay);
    delay = Math.min(delay * 2, 60_000);
  });
}

connect();

Python

With the websockets package, version 14 or later (pip install websockets):

import asyncio, json, os
import websockets
from websockets.exceptions import InvalidStatus

URL = "wss://api.lovearound.me/v1/stream"
TOKEN = os.environ["LOVEAROUND_TOKEN"]  # dev_…

async def main():
    delay = 1
    while True:
        try:
            async with websockets.connect(
                URL,
                additional_headers={"Authorization": f"Bearer {TOKEN}"},
                ping_interval=30,
            ) as ws:
                async for raw in ws:
                    msg = json.loads(raw)
                    if msg.get("type") == "ready":
                        delay = 1
                        print("online")
                    ev = msg.get("event") or {}
                    if msg.get("type") == "event" and ev.get("type") == "signal" and ev.get("v") == 1:
                        print("💗 someone thought of you")
        except InvalidStatus as e:
            if e.response.status_code == 401:
                raise SystemExit("the token doesn't work")
        except (OSError, websockets.WebSocketException):
            pass  # dropped, 503, no network: just reconnect
        await asyncio.sleep(delay)
        delay = min(delay * 2, 60)

asyncio.run(main())
